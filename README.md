# Tinkle Trouble 1.1 — Vexora Labs

An original, non-explicit bathroom aiming arcade game. No nudity, body models, or sexual content. Original canvas game graphics and procedural audio; no external fonts, audio, or image downloads.

## Update an existing GitHub Pages game

For the new colorful design and splashing sound, replace these six root files in your existing repository:

`index.html`, `styles.css`, `core.js`, `game.js`, `audio.js`, `icon.svg`.

Wait for GitHub Pages to redeploy, then press Ctrl + F5. Keep the same repository URL to retain browser progress. This update keeps the storage key, save schema, game rules, coins, achievements, prices, daily rewards, and AdMob IDs unchanged.

For Android, use the full updated project and run `npm run sync`; rebuilding is necessary to update the installed app. Version 1.1.0 includes brighter menus, six richer theme palettes, glossy cartoon rendering, updated launcher art, and a continuous procedural splash/spray sound instead of the repeated plop tone. Release, pause, mute, and leaving a run stop the splash sound.

## Upload to GitHub

1. Extract this ZIP.
2. Upload the **contents** of `tinkle-trouble` into the root of a new repository, including `.github`, `.gitignore` and `.nojekyll`.
3. GitHub → Settings → Pages → Deploy from a branch → main → `/ (root)` → Save.
4. Open the Pages URL. Root `index.html` is immediately playable, with no web build required. AdMob is native Android only.

## Included gameplay

- 45-second classic rounds. Hold and drag to aim; release to stop. Keyboard arrows + space also work.
- Moving bowl, progressive difficulty, crosswind after 15 seconds, clean-stream multipliers up to ×4, floor-mess failure.
- Seeded daily timed challenges, unlimited retries, 200-coin completion bonus once per local day.
- Coins earned from score, eight automatic achievement rewards, seven-day daily reward cycle.
- Six room/seat/water themes. Buy/equip with coins. Emergency mops and automatic splash insurance.
- Pause, resume, new game confirmations, menu/back navigation, Android hardware back, automatic background pause.
- Original synthesized music, splash/plop sounds, vibration, reduced-motion preference.
- Device-local persistence, reset confirmation, schema validation. No cloud sync.
- Android AdMob: menu-only adaptive banner, interstitial at every third completed run when starting again (90-second cooldown), optional earned-reward coin doubling. No banners during play.

## Build Android on Windows

Install Node.js 22 or later, Android Studio, JDK 21, and Android SDK 36. Open a terminal **inside the extracted tinkle-trouble folder**:

```powershell
npm ci
npm test
npm run android
npm run open
```

`npm run android` builds `www`, adds Android if missing, synchronizes native plugins, and inserts the AdMob app ID into AndroidManifest.xml automatically. The first generation requires Internet access. The included Android source was generated by the official Capacitor CLI; no signed APK/AAB or private signing key is included.

In Android Studio, select a physical device and Run. Verify consent, banner, interstitial, reward, background pause, and hardware back. Build a signed AAB using Android Studio only after real-device testing.

For later edits:

```powershell
npm run sync
npm run open
```

## AdMob configuration

`config.js` is the one place for advertising IDs. It currently uses Google's Android demo application ID and demo banner/interstitial/rewarded IDs, with `testMode: true`.

Before live release:

1. Create a separate AdMob Android app for Tinkle Trouble, with three ad units (banner, interstitial, rewarded).
2. Replace `androidAppId` (contains `~`) and the three unit IDs (contain `/`) in `config.js`.
3. Set `testMode: false` only for the release build. Continue using demo IDs or registered test devices during development.
4. Configure the required consent messages in AdMob Privacy & messaging.
5. Add your real support contact email to `privacy.html`. Publish this policy on your own Pages URL and use that URL in your store listing. Do not use the Color Pop Rush policy for this separate game without updating it.
6. Run `npm run sync`, then rebuild Android.
7. Review the Play Console ads declaration, data safety answers, content rating, and intended audience against your actual app/SDK configuration.

AdMob cannot display native ads on GitHub Pages. Ads may be unavailable offline, without consent, or when no inventory is available; the game keeps working and unearned rewards are never granted.

## Files

- Root HTML/CSS/JS: GitHub Pages edition.
- `src/native.js`: actual imported Capacitor/AdMob native bridge source.
- `www/`: prebuilt Android web assets, including bundled `native.js`.
- `android/`: generated Android Studio project, Gradle wrapper, native plugin registration, and test AdMob application ID.
- `capacitor.config.json`: Android app name, package ID, web assets.
- `scripts/`: repeatable build and Android setup/configuration.
- `tests/`: deterministic gameplay, economy, save validation, daily and rewards tests.
- `.github/workflows/check.yml`: GitHub Actions tests/build checks.
- `package-lock.json`: exact dependency tree.
- `TEST_REPORT.md`: checks actually performed and remaining device checks.

## Known limits

Daily resets follow the device's local date. Progress is local and can be changed by editing storage or the device clock; this is a casual offline game, not a secure competitive economy. Unfinished runs earn no coins and consumed supplies are not refunded. The first free mop is included. Double coins applies to run coins only, excluding daily and achievement bonuses. Cosmetic purchases and supplies use earned coins; no real-money billing is included.
